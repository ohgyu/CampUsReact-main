# Campus LMS Mobile Web (React)

기존 Spring MVC 기반 LMS(Learning Management System) 프로젝트를  
모바일 환경에서도 사용할 수 있도록 React 기반으로 개발한 모바일 웹 프로젝트입니다.

기존 웹 LMS 시스템의 기능을 React를 이용하여 모바일 친화적인 UI로 재구성하고  
Spring REST API와 연동하여 모바일에서도 학습 관리 기능을 사용할 수 있도록 구현했습니다.

---

## Project Overview

이 프로젝트는 대학 교육 환경에서 사용되는 학습관리 시스템(LMS)을  
모바일 환경에서도 사용할 수 있도록 확장한 모바일 웹 애플리케이션입니다.

기존 Spring MVC 기반 웹 프로젝트의 기능을 REST API 기반으로 연결하고  
React를 활용하여 모바일에서도 접근 가능한 학습관리 시스템을 구현하였습니다.

## Description

이 프로젝트는 기존 Spring MVC 기반 LMS 프로젝트를  
React 기반 모바일 웹으로 확장한 프로젝트입니다.

React를 사용하여 모바일 친화적인 UI를 구현하였으며  
REST API를 통해 기존 LMS 시스템과 데이터를 연동하여  
PC뿐만 아니라 모바일 환경에서도 학습 관리 기능을 사용할 수 있도록 개발했습니다.
